# 创作台

一个单文件的写作台：世界观、大纲、人物、地图、对话、任务、版本、云备份。
打开 `https://makopedro.github.io/story-desk/` 即用，数据存在你自己的浏览器里。

## 给协作者

1. 用自己的 GitHub 账号生成 token（fine-grained，只授权 `MAKOPedro/STORY-D`，权限 Contents: Read and write）
2. 打开上面的网址 → 设置 → 云备份
3. 仓库填 `MAKOPedro/STORY-D`，粘贴自己的 token，点「拉取」

## 更新

`index.html` 更新后，GitHub Pages 会自动重新发布；刷新页面即为最新版。本地数据不受影响。
